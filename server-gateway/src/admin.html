Модели

Порядок — это порядок падения: запрос идёт с той, что назвал клиент, и дальше вниз по списку, через всех провайдеров. При переходе на следующую модель кулдауны ключей сбрасываются — квота считается по моделям, и ключ, упёршийся в одну, на следующей ещё жив. Цены за миллион токенов в долларах; пустая цена кеша означает, что кеш считается по полной.
